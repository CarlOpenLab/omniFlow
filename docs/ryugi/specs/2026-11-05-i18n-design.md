# OmniFlow 中英文界面（i18n）设计

## 意图与原因

OmniFlow 目前只有英文界面。用户希望支持国际化，并且能在中英文之间切换。
首次启动应跟随 macOS 的系统语言；切换后立即生效，下次启动保持。

## 目标

1. 界面默认跟随系统语言：系统首选语言里有中文就显示简体中文，否则英文。
2. 设置 → Appearance 里增加语言切换：系统 / English / 简体中文。
3. 切换即时生效，不需要重启；选择被持久化。
4. 英文文案与现状逐字一致，英文用户看不到任何变化。
5. 所有用户可见文案都有中英文：窗口内容、原生菜单栏、右键菜单、对话框、
   通知/撤销提示、空状态、工具提示、无障碍标签。
6. 有数量语义的文案使用 ICU 复数规则（英文 one/other；中文只用 other）。

## 非目标

- 不翻译技术值和协议标记：HTTP 方法、头部名、MIME、状态码、URL、
  JSON/HAR/cURL 术语、`{{变量}}` 语法、文件扩展名。
- 不翻译用户数据：请求名、环境名、采集到的 URL/头部/正文、种子数据名称。
- 不翻译底层系统或 Go 库返回的错误详情（我们自己的提示前缀会翻译，
  拼接的 `err.Error()` 原样保留）。
- 不做第三种语言、RTL、按请求切换语言、语言独立的日期/数字区域格式
  （历史工具提示的日期除外，见下）。
- 不重构视觉设计；只为中文排版做必要的宽度和文案微调。

## 反目标

- 半翻译界面（任何一屏中英文混杂）。
- 切换语言需要重启，或切换入口藏在不显眼的位置。
- 把技术标记翻译成中文，导致用户无法复制粘贴。

## 现有基础（已核实）

- Mygo 0.5.6 自带完整 i18n 设施：
  - catalog：`locales/<BCP47>.json`，ARB 风格，消息用 ICU MessageFormat；
  - `mygo generate` 在 catalogs 目录生成类型化的 `catalog_gen.go`；
  - `mygo.App.Locale()` 按系统首选语言解析；
  - `mygo.App.SetLocale(tag)` 即时切换并持久化（macOS 写入 app defaults），
    `SetLocale("")` 恢复跟随系统；
  - `mygo.App.OnLocaleChanged(fn)` 在语言变化时回调；
  - Mygo 自带的控件/菜单文案会跟随 `App.Locale()`，生成代码会自动链接
    `locales/zh-Hans` 包；
  - `mygo i18n check` 校验翻译完整性。
- 当前 UI 文案分布在 `cmd/omniflow` 的约 12 个文件，约 300+ 条。
- 现有 `plural(n, noun)`（view.go）和 `countLabel(name, n)`（composer.go）
  是硬编码英文复数/计数的，需要改成 ICU 消息。
- 现有测试断言英文字符串，依赖当前英文文案。

## 方案

### Catalogs 与生成代码

- `mygo.json` 增加：

  ```json
  "i18n": { "dir": "locales", "source": "en" }
  ```

- 新建 `locales/en.json`：源语言。所有值逐字保留当前英文文案。
- 新建 `locales/zh-Hans.json`：简体中文全量翻译。
- 运行 `go tool mygo generate` 生成并提交 `locales/catalog_gen.go`
  （生成代码要提交，保证不装 CLI 时 `go test ./...` 也能跑）。
- 生成代码会把 catalogs 的语言注册为 app 的语言，并链接 Mygo 的
  `zh-Hans` 内置文案。

### Key 命名

区域前缀 + 驼峰，扁平结构，同区域相邻排序，便于补全和审阅：

- `commonDone`, `commonCancel`, `commonSave`, `commonUndo`, `commonCopy`,
  `commonClose`
- `composerSend`, `composerParams`, `composerBody`, `composerAuth` …
- `sidebarCollections`, `sidebarHistory`, `sidebarEmpty` …
- `inspectorTitle`, `inspectorEmpty`, `inspectorFollow` …
- `settingsTitle`, `settingsAppearance`, `settingsLanguage` …（分节标题
  用 `settingsSection*`）
- `envTitle`, `envAddRow`, `envMissing*` …
- `caTitle`, `caInstallHint`, `caManage` …
- `menuFile`, `menuNewRequest`, `menuSettings`, `menuProxy` …
- `noticeSaved`, `noticeExported`, `noticeDeleted`, `noticeUndo*` …
- `flowCount`, `headerCount`, `historySent` …

同一个英文词在不同语境翻译不同时，必须用不同的 key（例如 Body 标签页 vs
正文；Start vs Start Capture）。

### 动态文案

现有 `fmt.Sprintf` / 字符串拼接改为 ICU 占位符，中文可自由调整语序：

- 流量计数：`{count, plural, one {# flow} other {# flows}}`，中文
  `{count, plural, other {# 条流量}}`。
- 录制副标题：`"Recording on {addr} · {count, plural, ...}"`。
- 过滤进度：`"{shown} of {total}"`。
- 无效 JSON：`"Invalid JSON at {line}:{column}"`。
- 环境变量缺失：`"{name} is not set in “{env}”. Add it under Environments,
  or choose another."`；无环境版本同理。
- 通知：`"Saved “{name}”"`, `"Exported {count, plural, ...} to {dest}"`,
  `"Deleted “{name}”"` 等。
- 历史工具提示的日期：`"Sent {at, date, ::MMMd} {at, time, ::jms}"`，
  中文 `"发送于 {at, date, ::MMMd} {at, time, ::jms}"`。
- 删除 `plural()` 和 `countLabel()`，全部改走 catalog。

### 语言状态与切换

- `internal/model.Prefs` 增加：

  ```go
  // Language is the language the app shows: "", "en" or "zh-Hans";
  // "" follows the system's preferred languages.
  Language string `json:"language,omitempty"`
  ```

  零值 `""` 即“跟随系统”，`DefaultPrefs` 不用改。
- 启动时 `applyPreferences()` 调用 `mygo.App.SetLocale(a.prefs.Language)`。
  这样框架自带的持久化不会和我们的设置打架，分段控件也能准确显示
  “系统 / English / 简体中文”中的哪一档。
- Settings → Appearance 的 Theme 行下方增加 Language 行：
  - 标签：`Language` / `语言`
  - 三档 segmented：`System` / `系统`、`English`、`简体中文`
    （语言名用自身语言书写）。
  - 选择后：写 `a.prefs.Language`、`savePrefs()`、`mygo.App.SetLocale(tag)`。
    选择 System 时传 `""`。
- 切换后原生 UI 自动重绘；自定义菜单栏标签不会自动变，所以在
  `WhenReady` 里注册 `mygo.App.OnLocaleChanged(func(string) { a.installMenu() })`
  重新构建菜单。窗口标题 `OmniFlow` 是品牌名，不翻译。
- 已显示的通知文本保持切换前语言直到过期，不做额外处理。

| Proxy Inspector / Inspector | 代理抓包 |
| Send / Sending | 发送 / 发送中 |
| Cancel | 取消 |
| Save / Saved | 保存 / 已保存 |
| Done | 完成 |
| Undo | 撤销 |
| Settings | 设置 |
| Collection(s) | 集合 |
| History | 历史 |
| Environment(s) | 环境 |
| Request / Response | 请求 / 响应 |
| Params / Headers / Body / Auth | 参数 / 请求头 / 请求体 / 认证 |
| Capture / Start Capture | 抓包 / 开始抓包 |

文案风格：简洁、标签不带句号；按钮用动词；中文使用全角标点；避免生硬
直译。正文类提示可以带句号。

### 代码接入

- 所有 UI 文件 import `github.com/CarlOpenLab/omniflow/locales`，把
  `ui.Text(c, "Settings")` 改成 `ui.Text(c, locales.SettingsTitle())`。
- 涉及文件：`cmd/omniflow/{app,view,sidebar,composer,inspector,settings,
  env,body,widgets,appearance,curl_import}.go`；`icons.go` 只有 SVG，
  不动；`internal/*` 不动。
- 菜单构建 `installMenu()` 全部改用 catalog 标签。
- README 的 Settings 条补一句语言切换。

### 测试与验收

- `cmd/omniflow` 增加 `TestMain`，用
  `i18n.SetLocaleFunc(func() string { return "en" })` 固定测试语言为英文，
  让现有英文断言不受开发机系统语言影响；退出前恢复。
- 新增 `i18n_test.go`：
  - `TestCatalogParity`：`locales/en.json` 与 `locales/zh-Hans.json` 的
    key 集合完全一致（`mygo i18n check` 也会查）。
  - `TestChineseRender`：临时把 locale 切到 `zh-Hans`，渲染请求编辑器/
    抓包/设置，断言代表性中文文案（如“发送”“设置”“代理抓包”），
    结束后切回英文。全局 locale 是进程级的，测试内不得并行。
  - `TestLanguageRow`：设置里三档都渲染；点击“简体中文”后
    `a.prefs.Language == "zh-Hans"`。
- 现有测试的英文断言保持不变。
- 若 `mygo.App.SetLocale` 在无窗口的测试环境会阻塞，加一个包级
  `var setAppLocale = mygo.App.SetLocale`，测试替换为空函数。这是实现期
  的细节判断。
- 验收命令：
  - `go test ./...`
  - `go tool mygo i18n check .`
  - `go tool mygo vet .`
- 人工验收：
  - `sh scripts/dev.sh`，在设置里切换三档，检查窗口、菜单栏、右键菜单、
    对话框、提示。
  - `go tool mygo dev -lang en-XA`：catalog 里的文案会变成带重音的
    `[Šéļéçţ ...]`，仍是普通英文的文案就是漏掉的。
  - 用 `OMNIFLOW_SNAPSHOT=1` 增加/检查中文快照，确认固定宽度控件没有
    截断（尤其设置的分段控件、侧栏、抓包表头）。

## 约束

- 必须使用 Mygo 自带 catalogs，不引入第三方 i18n 库，不手写查表。
- 英文源文案逐字保持现状。
- 生成代码与 catalogs 一起提交。
- 不改变现有偏好文件的兼容性：新字段可缺省，旧文件照常读取。

## 留给实现者的决定

- 每条 key 的具体命名（遵循上面的前缀约定）。
- 哪些消息需要 `@key` 元数据（只在占位符类型或语境需要时添加）。
- 中文译文的具体措辞，以术语表和风格为准。
- 语言行放在 Appearance 的具体位置（Theme 之后），分段控件宽度。
- 测试中 `App.SetLocale` 的处理方式（注入 seam 或直接调用）。
- 中文快照是否默认生成（建议 env-gated，和现有快照一致）。

## 对话中确定的事

- 首次启动跟随 macOS 系统语言（用户决定）。
- 英文保持现状作为源语言，中文为新增翻译（实现默认）。
- 语言只在界面上切换，不改变已有数据的语言（实现默认）。

## 风险

- **漏译**：300+ 条分散在 12 个文件。用伪语言 `en-XA` 检查 + grep 审计
  `ui.Text/ui.Button/.Label/.Tooltip/menu item/setNotice` 的遗漏。
- **固定宽度截断**：中文通常更短，但设置分段控件和表头可能更宽；用快照
  逐屏确认。
- **拼接语序**：所有拼接句改为整句 ICU 消息，禁止翻译半句再拼。
- **测试语言漂移**：必须固定测试 locale，否则中文开发机上现有测试会红。
- **框架持久化双写**：`SetLocale` 会写系统侧设置，我们同时写自己的 prefs；
  启动时以 prefs 为准调用 `SetLocale`，避免不一致。
